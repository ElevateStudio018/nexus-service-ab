# Nexus Service AB – hemsida

Statisk, responsiv hemsida för **Nexus Service AB** – byggservice, byggnadssnickeri, renoveringar, fastighetsskötsel och lokalvård.

Designen kombinerar Upsala GK:s mörka, exklusiva känsla (helbildshero, statusrad, bildrutnät med text över bild) med Ängö Entreprenads kraftfulla entreprenadprofil (orange "Varför välja oss"-band, alternerande tjänstesektioner och en flytande ringknapp). Typsnitt: Poppins.

## Sidor
| Fil | Innehåll |
| --- | --- |
| `index.html` | Startsida med videohero, tjänster, motto, arbetsgång |
| `tjanster.html` | Översikt över alla tjänster + ROT/RUT |
| `byggservice.html` | Byggservice |
| `snickeri.html` | Byggnadssnickeri |
| `renoveringar.html` | Renoveringar |
| `fastighetsskotsel.html` | Fastighetsskötsel |
| `lokalvard.html` | Lokalvård |
| `om-oss.html` | Om företaget, bolagsfakta, kundgrupper |
| `kontakt.html` | Kontaktuppgifter, öppettider, offertformulär (sms), karta, FAQ |
| `404.html` | Felsida |

## Resurser
- `assets/css/style.css` – all design
- `assets/js/main.js` – meny, öppet/stängt i realtid, videokontroll, scroll-animationer, offertformulär som skapar ett färdigt sms
- `assets/video/` – bakgrundsfilmer (klipp från [Mixkit](https://mixkit.co), fri licens) – herofilmen finns i 1080p och 540p för mobil
- `assets/img/` – foton från [Unsplash](https://unsplash.com) (Unsplash-licensen) och logotypen `mark.svg`

Byt gärna ut foton och filmer mot egna projektbilder.
